# Gezira Solutions - Membership

نسخة منظومة العضويات القديمة من مشروع `Server`، تشمل التجديد والتقسيط والإيصالات والتقارير والصلاحيات والترخيص الموقّع المرتبط بالسيرفر، بالإضافة إلى مشروعي Backend وFrontend للسوبر أدمن داخل `SuperAdmin`.

## التشغيل

```powershell
cd Server
npm ci
# Create .env locally using .env.example and your own database/accounting settings.
npm run build
npm start -- -p 3001
```

للتطوير فقط: `npm run dev` من داخل `Server`.

النشر يحتاج PostgreSQL به مخطط المنظومة الأساسي وبياناته. ملفات SQL هنا تحديثات للمنظومة الموجودة، وليست نسخة بيانات أو تهيئة كاملة لقاعدة فارغة. احتفظ بنسخة احتياطية وراجع كل سكربت قبل تنفيذه.

أداة إصدار التراخيص والمفتاح الخاص **غير موجودين في هذا المستودع**، ولا يجب رفعهما إلى العميل.

## أمان النسخة

لا تتضمن النسخة `.env` أو كلمات مرور فعلية أو صور/ملفات الأعضاء أو النسخ الاحتياطية أو اللوجات أو مفاتيح الجلسات. إعدادات دخول ERP في نسخة النشر تقرأ من `ERP_DB` و`ERP_USERNAME` و`ERP_PASSWORD`، وإعدادات اتصال ERP التجريبي من المتغيرات التي تبدأ بـ `ERP_DEMO_`؛ لا توجد كلمات مرور افتراضية في الكود المنشور.

الصور العامة والشعار والخطوط وقوالب الطباعة مرفقة. لقطات المقارنة الداخلية `docs/ui-modernization-baseline` ليست جزءًا من نسخة النشر لأنها تحتوي مصادر تاريخية خاصة؛ اختبارات المقارنة التي تعتمد عليها تحتاج هذه اللقطات من الأرشيف الداخلي المصرح به.
