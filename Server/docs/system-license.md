# ترخيص منظومة العضويات

## النشر

1. ارفع ملفات المنظومة المحدثة، بما فيها `config/license-public-key.pem`. المفتاح عام ومطلوب للنشر. لا ترفع أداة الإصدار أو أي ملف مفتاح خاص.
2. بعد التأكد من اتصال Prisma بالداتابيز الصحيحة، نفذ من Server:

```powershell
npx prisma db execute --file scripts/apply-system-license.sql --schema prisma/schema.prisma
npm run build
npm start -- -p 3001
```

3. سجل الدخول بحساب `Admin@gmail.com` وافتح `/activation`.
4. انسخ بصمة السيرفر، وأصدر لها ترخيصًا من أداة الشركة على جهاز المالك.
5. ارفع ملف `.license` وأكد بكلمة مرور حساب الشركة. يتسجل التفعيل في `security_audit`.

لو IIS ينهي HTTPS أمام Next.js، اضبط `APP_PUBLIC_ORIGIN` في بيئة تشغيل Next.js على عنوان الموقع الفعلي مثل `https://members.example.com`، ثم أعد التشغيل. يستخدم للتحقق من مصدر طلب التفعيل، وليس لتعطيل الترخيص.

الترخيص المحلي الصادر لجهاز التطوير لا يعمل على سيرفر مختلف، حتى عند نقل الداتابيز. لا توجد مهلة تلقائية أو تفعيل تلقائي عند فقد الترخيص. لا تُعد توليد مفاتيح الإصدار على العميل.

## الانتهاء

الترخيص ينتهي أول يوم 1 يونيو قادم، الساعة 00:00 بتوقيت `Africa/Cairo`. لا توجد تنبيهات مسبقة. البوابة تتحقق على السيرفر عند كل استدعاء للصلاحيات، بما فيه التحصيل والتقارير والتصدير والطباعة وإدارة الأدوار. الواجهة المفتوحة تضبط مؤقتًا بمدة محسوبة من ساعة السيرفر، وتعيد التحقق دوريًا وعند الرجوع للنافذة. الطلبات الجديدة بعد القفل مرفوضة، والعمليات التي بدأت قبل الانتهاء تظل خاضعة لمعاملاتها المحاسبية؛ لا نحذف دفعات أو نوقف PostgreSQL.

تسجيل الدخول والخروج وشاشة/API التفعيل تظل متاحة؛ تفاصيل التفعيل وتطبيق الترخيص لحساب الشركة الحقيقي فقط، ولا تُقبل هوية من localStorage. التفعيل يتطلب كلمة مرور الحساب والتحقق من مصدر الطلب والتوقيع والبصمة والصلاحية الزمنية.

## البصمة والوقت

Windows فقط: بصمة SHA-256 لهوية Windows ومعرف جهاز النظام؛ لا نعتمد على IP أو MAC. لا تُعرض القيم الأصلية، بل بصمة فقط. تعذر قراءة الهوية يقفل النظام ولا يستخدم بصمة بديلة قابلة للتغيير. تغيير Windows أو هوية الجهاز الافتراضي قد يحتاج إصدار ترخيص جديد. احتفظ بالمفتاح العام عند نقل ملفات البرنامج.

يوجد سجل لآخر وقت تحقق؛ رجوع ساعة السيرفر بأكثر من خمس دقائق عن الوقت المسجل يقفل التحقق حتى تصحيح الساعة. التحريك الزمني الخارجي أو استعادة قاعدة البيانات أو نسخ VM بهويته كاملة أو تعديل الكود بواسطة مدير الجهاز ليست محمية حماية مطلقة في نظام ترخيص offline. لا توجد خدمة إنترنت موثوقة للتحقق من الساعة في هذه النسخة.

## أداة الشركة

الأداة المنفصلة: `D:\ACTIVITIES\Gezira-License-Issuer\Open-Issuer.cmd`.
المفتاح الخاص محمي بـ DPAPI لحساب Windows الذي هيّأ الأداة. نقل مجلد الأداة وحده إلى حساب/جهاز مختلف لا يضمن فك المفتاح. احتفظ بنسخة احتياطية آمنة لحساب/نظام Windows، ولا تضع نسخة المفتاح عند العميل. فقد المفتاح يستلزم خطة تغيير ونشر المفتاح العام للعملاء؛ لا يوجد مفتاح استرجاع في المنظومة.
