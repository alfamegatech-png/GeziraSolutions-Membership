# Regression Checks

Run from Server using the existing Node dependencies:

```powershell
node --test tests/stability.test.cjs tests/regression/calculation-baseline/compare.test.cjs tests/regression/payment-date.test.cjs tests/regression/presentation-behavior.test.cjs
```

The 76 tests do not write to the database. Financial inputs are synthetic; transaction clients are mocks.
The original 53 golden outputs are captured from the source snapshot, hash-locked, and never regenerated by these tests.
Do not edit golden.json to accommodate changed financial results.

The source snapshot and SHA-256 file manifest live in docs/ui-modernization-baseline/.
Reports explain tested and untested functionality. Financial forms, aggregation, schema and HTTP/auth routes are compared with original source.
Three original date-related formula sites differ with explicit user authorization; timestamp tests cover that exception.

Live read-only browser checks are available in the workspace's presentation-build/compare-ui-browser.cjs and check-ui-workflows.cjs.
They require the bundled Playwright runtime and a running local Server; set UI_ORIGIN to its URL.
They do not submit membership payments or destructive forms. Original browser captures remain in outputs/ui-modernization/before-confirmed/.

Do not deploy test execution copies, source snapshots, node_modules junctions or browser screenshots to a public web directory.
